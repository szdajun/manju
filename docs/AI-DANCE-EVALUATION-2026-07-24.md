## 四、建议的 ep05 结构 (若做)

```
ep05_dance/
├── assets/characters/kid_dance/        # "小孩装大人" 立绘 + LoRA
├── scripts/
│   ├── gen_ep05_dance_keyframes.py     # 5-10 镜, 每镜明确表情+动作+卡点
│   ├── gen_ep05_dance_video.py         # Wan2.1-Animate / 视频驱动迁移
│   ├── beat_sync.py                    # librosa BGM 节拍 → 字幕/切镜
│   └── assemble_ep05.py                # BGM + 双字幕 + 竖屏
├── prompts/ep05/                       # 反差 prompt 套
└── docs/dance-style-design.md          # 8 表情参考库
```

### MVP 时间预估 (单 15s 出片)
- 立绘 + 角色 LoRA: 1.5h
- 连续动作生成管道: 2-3h
- BGM 卡点 + 双字幕: 1h
- 拼装 + 竖屏导出: 30min
- **总计 ~5-7h, GPU 重 (Wan2.1 类模型)**

## 五、关于 "孩子装大人表情丰富" 的技术深度

1. **LoRA 锁静态脸型/五官, 不锁表情**. IPAdapter 锁脸 + 凹嘴笑会冲突丢脸
2. **解法**: 每镜独立 prompt 写"歪嘴+挑眉+挺胸", 5 镜 5 表情全 keyframe 精雕
3. **进阶**: 表情库预制 (8 PNG) + 角色骨架 + 合成 — 偏虚拟主播路线, **超出 AI 漫剧范畴**
